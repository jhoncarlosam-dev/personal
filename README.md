# Punto de vida

Cuaderno personal de Jhon Carlos: el punto en el que está, el día a día y reportes que se pueden imprimir.

```bash
npm install
npm test
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000). En esta máquina los datos quedan en `.pglite`. Publicado, usa la base Postgres de la app.

Publícalo como **privado**. El punto de partida incluye salario, salud y estado civil.
